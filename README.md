# Solar Panel Voltage Monitoring System

My first Arduino-based renewable energy project.

## Project Report

[Download the Project Report](./Solar_Panel_Monitoring_Report.pdf)

## Project Overview

This project measures the voltage output of a solar panel using an Arduino Uno and a voltage divider circuit.

### Results

| Configuration | Indoor | Outdoor |
|--------------|---------|---------|
| 10kΩ + 5.1kΩ | 10.69 V | 14.80 V |
| 10kΩ + 10kΩ | 8.54 V | 10.00 V |
